📋 Indian Number Format

Pattern: XX DD YY ZZZZ
XX: 2 letters (State Code)
DD: 2 digits (District Code)
YY: 2 letters (Series)
ZZZZ: 4 digits (Registration)

🏷️ Indian State Codes

📝 Examples

  • DL 01 AB 1234 - Delhi
  • MH 02 CD 5678 - Maharashtra
  • KA 03 EF 9012 - Karnataka
  • TN 04 GH 3456 - Tamil Nadu
  • UP 05 IJ 7890 - Uttar Pradesh
